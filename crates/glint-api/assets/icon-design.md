# Glint API icon

The current icon is a flat cobalt-blue rounded square with a white code/connection symbol. Two opposing brackets surround two short horizontal paths representing request and response. There are no glass effects, gradients, highlights, or shadows. The exterior is transparent.

`glint-api-icon.svg` is the editable vector source. `glint-api-icon.png` is its 1024 × 1024 export rendered with the project's resvg dependency, embedded as the macOS Dock icon when running the example with Cargo.

## Design brief

Simple contemporary developer-tool icon. Solid #2563EB tile and #FFFFFF glyph. Consistent rounded strokes, precise symmetry, generous negative space, readable at 24–32 px. No text or decorative effects.

The final artwork is drawn directly in SVG. Built-in ImageGen edits were attempted but both requests failed with network connection errors; the final icon was not generated by ImageGen.
