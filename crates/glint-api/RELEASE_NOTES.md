Glint API 0.1.3 — 目录模板、变量提取与 cURL

- 双击集合或目录进入设置，按项配置请求地址、鉴权、请求头、请求体、前后置动作等默认模板；子目录可覆盖父级配置，新请求继承最终生效的默认值。
- 全局环境切换移至顶部栏，请求切换和恢复版本不再改变环境。模板变量支持补全，缺失变量或动作执行失败通过具体错误提示和 Toast 展示。
- 新增后置动作：通过多组 JSONPath 从响应提取变量，原子写入发送时的环境；支持直接从 JSON 响应点选路径、匹配预览与敏感值隐藏。
- 请求体支持 application/x-www-form-urlencoded，包括重复字段、空值及模板变量。
- 从“更多”菜单或命令面板粘贴 cURL 导入请求；响应面板可复制发送时的 cURL 快照，包含已解析变量和前置动作请求头，历史记录切换时同步恢复。
- 格式化 JSON 响应支持对象、数组及数组项折叠，保留原始行号；复制仍使用完整内容，搜索隐藏结果时自动展开。搜索工具栏与代码块合并，格式切换改用分段控件。
- 版本历史支持自定义标签；请求历史支持删除，悬停显示操作入口并通过 Popover 二次确认。请求和目录删除也加入二次确认。
- 侧栏支持拖拽调整宽度，搜索输入框随宽度变化；修复环境管理中长变量值溢出，编辑时可横向滚动。
- 更新入口移至左下角图标栏，详情通过 Popover 展示；精简顶部栏重复的主题切换入口，并统一应用图标。

下载 `Glint-API-0.1.3-windows-x64-setup.exe` 安装。升级保留工作区数据，安装包附带 `.sha256` 校验文件，尚未进行代码签名。缺少 WebView2 时会安装运行时，该步骤需要联网。

已安装 0.1.1 或更新版本可在应用内检查更新、校验安装包后升级并重启；0.1.0 需手动安装一次。旧请求和历史继续兼容；旧历史尚未保存 cURL 快照，需要重新发送后才可导出。

cURL 导入支持常见 Bash / POSIX 格式。文件正文、multipart、自动重定向及其他尚不支持的选项会显示具体错误，不执行粘贴的命令或读取本地文件。
