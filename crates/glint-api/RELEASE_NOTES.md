Glint API 0.1.2 — 插件与请求前置动作

- 新增独立插件管理页，支持本地插件、多个远程插件源及签名验证后的安装。
- 插件可注册多个请求前置动作。通过 Switch 独立启用，拖动卡片左侧手柄调整执行顺序；动作与权限绑定随工作区保存。
- 内置 WPS KSO-1 签名动作，环境中配置 `wps_app_id` 和敏感变量 `wps_app_key` 后启用。
- 插件源列表采用卡片布局；添加表单位于 Dialog，支持签名验证及错误保留。
- 修复 Windows 验证方式下拉框文本换行问题。
- 提供可自部署的插件仓库服务及发布 CLI，共享插件协议可用于其他 Glint 应用。

下载 `Glint-API-0.1.2-windows-x64-setup.exe` 安装。Setup 自动创建桌面与开始菜单快捷方式，升级保留工作区数据。缺少 WebView2 时会安装运行时，该步骤需要联网。

已安装的 0.1.1 可在应用中检查更新、下载校验后安装并重启；0.1.0 需手动安装一次。安装包未进行代码签名，附带 `.sha256` 校验文件。

插件仓库及客户端配置说明见仓库内 `docs/plugin-registry.md`。客户端获取插件不需要发布令牌。
