Glint API 0.1.6 — 请求多窗口预览与代理抓包

- 请求标签页右键菜单新增“在独立窗口中打开”，可同时打开多个只读预览窗口，比较打开时的请求配置、未保存内容、最近发送报文及已有响应；WebSocket 请求可查看已有消息快照。
- 子窗口沿用主窗口的模板变量显示、悬浮提示和解析规则，正确应用请求所属集合的变量覆盖；JSON 响应支持对象与数组折叠，切换响应标签保留折叠状态，复制包含完整内容。
- 请求标签页支持右键关闭其他、左侧或右侧标签，改进标签滚动和关闭交互；请求配置与响应面板之间可拖拽调整高度。
- 代理新增 HTTP/HTTPS 监听、证书生成及导入导出、浏览器独立会话和抓包面板，支持查看请求与响应、搜索过滤及流式转发。
- cURL 导入可跳过不支持的选项并给出提示，改进常见命令兼容性。
- 改进代码块的文本选择、复制和滚动交互，修复请求体滚动与 MCP 连接恢复问题。

Windows：下载 `Glint-API-0.1.6-windows-x64-setup.exe`，也可从应用内“软件更新”检查 GitHub 更新。

macOS：Apple Silicon 下载 `Glint-API-0.1.6-macos-arm64.dmg`，Intel 下载 `Glint-API-0.1.6-macos-x86_64.dmg`，将应用拖入 Applications 替换升级。

升级保留工作区数据。安装包附带 `.sha256` 校验文件；macOS 包使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证，Windows 包未进行代码签名。
